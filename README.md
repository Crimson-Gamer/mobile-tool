# Mobile Tools

## 📱 About

Mobile Tools focuses on making Mindustry more convenient to play on Android and other mobile devices.

The mod is lightweight and designed to work alongside the normal Mindustry experience.

## ✨ Features

* 📱 Mobile-focused tools
* ⚙️ Lightweight JavaScript-based functionality
* 🎮 Designed for Mindustry
* 🔧 Easy to update and maintain
* 🚀 Open-source project

## 📥 Installation

1. Open Mindustry.
2. Go to the **Mods** menu.
3. look up mobile tools then install
4. Restart Mindustry if necessary.
5. Enable **Mobile Tools**.

## 🔄 Updates

New versions will be released through the project's GitHub Releases.

When a new version is available:

1. Download the newest release.
2. Install/import it into Mindustry.
3. Replace the previous version if Mindustry asks you to.
4. Restart the game if necessary.
